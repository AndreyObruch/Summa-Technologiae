# Сумма технологии (Summa Technologiae)

Двухдневный офлайн-семинар об искусственном интеллекте. Санкт-Петербург, 24–25 октября.
Лозунг: «Четыре грани ИИ: наука, практика, творчество, прогноз».

## О проекте

Одностраничный лендинг семинара с регистрацией участников.
Название — отсылка к трактату Станислава Лема «Summa Technologiae» (1964).

## Структура

- `index.html` — лендинг целиком (HTML + CSS + JS в одном файле)

## Запуск локально

Открыть `index.html` в браузере.

## Секции семинара

1. Научно-техническая база ИИ
2. Практическая лаборатория личного ИИ
3. Применение ИИ в образовании, творчестве и профессиях
4. Футурология, история, этика, риски
